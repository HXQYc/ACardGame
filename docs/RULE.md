# 捉黑 A（ACard）游戏规则

本文整理已确认的基础规则。进贡为可选扩展，暂不启用；其未确认事项列于第8节。通信编码、超时和启动控制等具体设计值由 PROTOCOL.md 与 BUILD.md 定义，不扩充本文玩法。

## 1. 人数、牌组与阵营

支持三人或四人。使用一副扑克牌，去掉 2、3、4 和大小王，共 40 张：每种花色各有 5、6、7、8、9、10、J、Q、K、A。

### 四人局

- 黑桃 A、梅花 A 为身份牌。
- 开局持有任意身份牌的玩家属于黑方，其余玩家属于红方。
- 身份牌分属两人时，为二对二；同属一人时，为一对三，该玩家称为“黑户”。

### 三人局

- 只有黑桃 A 为身份牌，持有者属于黑方，另外两人属于红方。
- 梅花 A 保留为普通牌。

身份起初隐藏，真实阵营由服务端依据开局手牌确定。

## 2. 发牌与先手

- 发完全部 40 张牌：四人每人 10 张，三人一人 14 张、另外两人各 13 张。
- 第一局随机选择第一张牌的接收者；之后第一张牌发给上一局第一名。
- 红桃 5 持有者先出牌，首次出牌不要求包含红桃 5。
- 按固定座位方向，每人一张轮流发牌；行动也沿同一方向。程序中座位按编号升序环形排列，下文“下一位”跳过已出完者。

## 3. 牌型与大小

点数顺序：`5 < 6 < 7 < 8 < 9 < 10 < J < Q < K < A`。

“管牌”指打出能够压过当前上一手的合法牌型。

| 牌型 | 组成 | 管牌范围与比较 |
| --- | --- | --- |
| 单牌 | 一张牌 | 只能管单牌，比较点数 |
| 对牌 | 两张同点数牌 | 只能管对牌，比较点数 |
| 顺子 | 3～10 张连续点数，每个点数一张 | 只能管相同张数的顺子，比较最高点数 |
| 连对 | 至少 3 对连续点数，每个点数恰好两张 | 只能管相同对数的连对，比较最高点数 |
| 炸弹（炮） | 三张同点数牌 | 可管单牌、对牌、顺子、连对；炸弹间比较点数 |
| 雷 | 四张同点数牌 | 可管单牌、对牌、顺子、连对、炸弹；雷间比较点数 |

- 顺子与连对中的 A 只能位于最高端。例如 QKA 合法，A56 不合法。
- 允许拆牌：手中有四张 5 时，可以出一张、两张、三张，也可以取一张组成顺子。
- 牌型根据本次打出的牌判断，不根据完整手牌判断。
- 连对中每个点数严格为两张，555666777 不属于连对。
- 雷高于炸弹，不受两者点数高低影响。
- 同类牌型必须严格更大才能管，相同大小不可管；花色不参与大小比较。

## 4. 身份牌优先与公开

一次出牌使用 k 张 A 时，必须尽可能优先使用手中的身份牌 A，不足部分再使用其他 A。该限制适用于所有含 A 的牌型。

- 四人局优先使用黑桃 A、梅花 A。
- 三人局只优先使用黑桃 A，梅花 A 为普通 A。
- 打出身份牌后立即公开该玩家属于黑方。
- 不额外公开其剩余手牌或身份牌数量。黑户打出一张身份牌时，只标记黑方，不直接公布其为黑户。
- 打出的牌及牌型为公共信息。

## 5. 普通回合与名次

### 自由领出

开局先手或获得领出权的玩家，可以出任意合法牌型，无需管住上一轮的牌。自由领出时禁止过牌。

### 跟牌与过牌

- 非自由领出时，可以管牌或过牌。
- 不论是否能管住，都允许主动过牌；接风拒绝产生的强制出牌除外。
- 有人出新牌，该手成为新的管牌目标。
- 最后出牌者仍有牌，且其余尚未出完牌的玩家均连续过牌时，本轮结束，由最后出牌者自由领出。
- 出完牌的玩家立即取得下一个名次，退出后续行动和接风询问。
- 只剩一人有牌时，直接记录其为末名并结算，无需打完剩余牌。
- 普通过牌后，别人打出新牌，再轮到自己时可以继续跟牌。

## 6. 接风

A 打出最后一手并出完牌后，沿行动方向的下一名仍有牌的玩家 B 为接风者。A 的最后一手仍为管牌目标。

B 可任选：管牌、过牌、申请接风。

### 不申请接风

- B 管牌：以 B 的牌为目标，恢复普通回合。
- B 过牌：其余仍有牌的玩家依次行动。
- 所有剩余玩家最终均过牌，无人管住 A 时，由 B 自由领出。

### 申请接风

1. 从 B 后面的下一名仍有牌玩家开始，按行动顺序轮询，跳过 B 和已出完者。
2. 询问及回答均公开；给风只是表态，无需交牌或出牌。
3. 无法合法管住 A 的玩家只能同意，不能拒绝。
4. 能合法管住 A 的玩家可同意或拒绝，包括使用合法炸弹或雷的情况。
5. 第一个拒绝立即生效，停止后续询问。
6. 全部同意时，B 自由领出。

### 拒绝后的强制管牌

设第一个拒绝者为 R：

1. B 先选择管牌或过牌，不能对同一手再次申请接风。
2. B 管牌时，恢复普通出牌顺序，目标改为 B 的牌，R 的强制出牌义务取消。
3. B 过牌时，跳过中间已同意的玩家，直接由 R 行动。
4. R 必须合法管住 A，不能过牌。
5. R 出牌后恢复正常流程；若 R 同时出完，则再次执行出完后的接风处理。

例如 A → B → C → D：A 出完，B 申请，C 同意、D 拒绝。B 若管牌，之后 C 正常行动；B 若过牌，跳过 C，由 D 强制管 A。

任何时刻因出牌只剩一人有牌时，优先记录末名并结算，不再接风。

## 7. 胜负

名次按出完顺序记录，第一名最先出完。胜负依据黑方名次判定。

### 四人局：两名黑方

| 黑方名次 | 结果 |
| --- | --- |
| 1、2 | 黑方胜 |
| 1、3 | 黑方胜 |
| 1、4 | 平局 |
| 2、3 | 平局 |
| 2、4 | 红方胜 |
| 3、4 | 红方胜 |

### 四人局：黑户

| 黑方名次 | 结果 |
| --- | --- |
| 1 | 黑方胜 |
| 2 或 3 | 平局 |
| 4 | 红方胜 |

### 三人局

| 黑方名次 | 结果 |
| --- | --- |
| 1 | 黑方胜 |
| 2 | 平局 |
| 3 | 红方胜 |

## 8. 可选扩展：进贡（暂不启用）

进贡在下一局发牌后、正式出牌前执行。

已明确原则：

- 上局输方每名玩家各进一张贡牌。
- 贡牌为手中最大的非身份牌：三人豁免黑桃 A，四人豁免黑桃 A、梅花 A。
- 收贡赢家向对应进贡者还一张牌。
- 红桃 5 不应作为还牌，是否严格禁止尚未确认。

待确定：输家与赢家对应关系、一对多时收还数量、同点数贡牌选择、平局处理及交换顺序。本节尚不构成完整可执行规则。

## 9. 已确认的公开信息与异常处理

玩家出完牌时不额外公开阵营；正常结算时公开全部阵营。第一版协议选择不公开其他玩家的剩余手牌。

中途断线或主动退出则中止本局，不记本局胜负，不产生进贡结果。单机与 AI 留作未来扩展，进贡和主动明牌加倍暂不启用。

具体网络行为和状态公开范围见 [PROTOCOL.md](PROTOCOL.md)。
